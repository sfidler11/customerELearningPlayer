Waffles 101 Course Player — Style & Behavior Guide

Reference for AI tools and developers building or extending the eLearning course player shell and its content pages. Source of truth: CoursePlayer.dc.html.

1. Principles

  1. Content first. The shell (header, menu, control bar) frames the page and never competes with it. Chrome is white/neutral; color is reserved for progress, primary actions, and status.
  2. Never cover content. Captions, section progress, and the desktop menu resize the content area rather than overlay it. Only the tablet menu, phone menu, and modal dialogs overlay.
  3. Always oriented. Learners can always see course completion, current page, and page count.
  4. Accessible by default. WCAG 2.1 AA contrast, visible focus on every control, ≥44×44px targets, labels on every icon button.
  5. Plain, warm copy. Short sentences. No em dashes in learner-facing copy. No jargon.

4. Spacing, radius, elevation

  • Spacing scale: 4, 6, 8, 10, 12, 14, 16, 20, 24, 28, 32, 40, 48, 56, 64.
  • Stage padding: desktop/tablet 28px 32px 14px, phone 12px 12px 10px, title page 0 (full-bleed).
  • Radius: 8px controls, 10px phone buttons and slide image panels, 12px cards/content region/accordion items, 14px dialogs, 99px pills and progress bars, 50% round buttons.
  • Shadows (subtle only):
    • Card: 0 1px 2px rgba(30,28,26,.05), 0 6px 20px rgba(30,28,26,.05)
    • Raised (open accordion item, toast): 0 1px 2px rgba(30,28,26,.05), 0 8px 24px rgba(30,28,26,.07)
    • Primary button: 0 2px 6px rgba(168,70,0,.22)
    • Tablet drawer: 12px 0 32px rgba(30,28,26,.14)
    • Dialog: 0 16px 48px rgba(30,28,26,.2)
  • Avoid gradients except the title page scrim and striped image placeholders. Don't put a colored accent stripe on the left edge of cards.

5. Breakpoints & layout

The breakpoint comes from the player container width (ResizeObserver), not the window, so the player adapts inside any frame.

"Short" mode applies when the player is under 700px tall. It shrinks the title page type and gaps and hides secondary meta.

Vertical stack (all modes): Header → Content stage (flex:1) → Section progress bar → Captions panel (optional) → Control bar.

Content region has max-width 1180px and is centered in the stage.

6. Components

6.1 Header

  • Menu toggle: outlined, icon + "Menu" label. The icon swaps to × when open, and the button gets aria-expanded and aria-controls="course-menu".
  • Course title: "Waffles 101", with the module subtitle (Module N · Title) below.
  • Course Completion: label Course Completion NN% plus an 8px bar (brand fill). Uses role="progressbar" with aria-valuenow.
  • Save & exit: outlined button. Opens the exit dialog (§7.6).

6.2 Course menu (drawer)

  • Header: "Course contents", a close button (44px), then "N of 12 pages complete" with a 6px progress bar.
  • Pages are grouped by module. Each module heading shows the eyebrow MODULE N, the module title, a done/total count, and a "Complete" pill when every page is finished.
  • Page rows (min-height 48px, full-width button) show a status icon, the title, and the duration.

| Status | Icon | Sub-label | |---|---|---| | Complete | Filled brand circle with white check | none | | In progress (visited, not finished) | Half-filled brand ring | "In progress" (muted) | | Not started | 2px #C9C3BC ring | none | | Current | brand ring with center dot, row bg brand-tint, title bold | "You are here" (or "You are here · Complete"), brand-strong |

  • The current row has aria-current="page", and every row's aria-label includes its status.
  • Learners can jump to any page in any order.
  • Selecting a page closes the menu on tablet and phone; on desktop it stays open.

6.3 Content region

  • White card with 12px radius, 1px line border and the card shadow. It scrolls internally if its content overflows.
  • Set role="region" with aria-label="Page N: Title".
  • Page templates are listed in §8.

6.4 Section (page) progress bar

  • Sits directly below the content region: a single 6px bar with track background and brand fill.
  • It shows narration progress for the current page only (t / duration) and resets on navigation.
  • No text. The tooltip reads "Title: m:ss of m:ss", and it uses role="progressbar" with an accessible label.

6.5 Control bar

Desktop/tablet uses a three-column grid (1fr auto 1fr):

  • Left: Back, an outline button (chevron + label), disabled on page 1.
  • Center, as the audio group (role="group"): Replay (44px ghost), Play/Pause (48px circle, brand-strong), Mute toggle (44px ghost), volume slider (96px, accent-color: #CC5500), and the time m:ss / m:ss (hidden on tablet).
  • Right: Captions toggle (CC glyph + label; aria-pressed; active = brand-tint bg, brand border, brand-strong text), page counter N of 12, and Next (primary, brand-strong), disabled on the last page.

Phone has two rows, built for one-thumb use:

  1. Secondary row (44px): Replay, Mute, Captions (bordered, CC + label), then a spacer, the time readout, and a pill page counter.
  2. Primary row: Back (flex:1, 52px) · Play (60px circle) · Next (flex:1, 52px, primary).

The volume slider is omitted on phone because the device buttons handle volume; mute stays.

6.6 Captions / transcript panel

  • Toggled by the CC button. It docks below the content and above the control bar, and the stage shrinks to fit it.
  • It's a card with a "CC · TRANSCRIPT" label and a close button.
  • Narration shows as sentences, and the active sentence gets ink text on a brand-tint-2 highlight.
  • Max height is 84px on desktop and 112px on phone, scrolling internally. Uses aria-live="polite".

6.7 Toast: "Section Completed"

  • Appears bottom-right of the content area (20px inset; 12px on phone) when a page is completed for the first time.
  • White card with a 24px brand check circle and 14px/600 text.
  • Fades and slides up 8px over 250ms, then auto-dismisses after 3.2s.
  • role="status" with aria-live="polite". It is not clickable (pointer-events: none).

6.9 Icons

  • Stroke icons on a 24×24 viewBox: stroke: currentColor, stroke-width 2 (2.2 for chevrons, 3–3.5 for checks), round caps and joins, 18–22px.
  • Play/pause are filled shapes.
  • Every icon is aria-hidden="true", and its button carries the label.

7. Behavior

7.1 Navigation

  • Back/Next move by one page, and the menu jumps anywhere.
  • Every navigation sets narration time to 0, marks the page visited, and saves state.
  • Autoplay: navigating to a page that is not yet complete starts narration automatically. Completed pages open paused at 0:00.
  • The first load doesn't autoplay, because browsers block audio that starts before any interaction.

7.2 Completion rules

  • A page is complete only when its narration plays to the end. Visiting a page does not complete it.
  • Page states: not started → in progress (visited) → complete.
  • A module is complete when all of its pages are complete.
  • Course Completion % = completed pages / total pages, rounded.
  • Replaying a completed page never un-completes it and does not re-trigger the toast.
  • When content pages add interactions (quizzes, activities), extend the completion rule to cover them.

7.3 Audio

  • Play/Pause toggles playback, and pressing Play at the end restarts from 0.
  • Replay jumps to 0 and plays.
  • Mute toggles. Setting the volume to 0 shows the muted state, and unmuting from 0 restores the volume to 50.
  • Time ticks once per second (the demo simulates audio with a timer).

7.4 Captions

  • Off by default, and the setting persists for the session.
  • The active sentence index is floor(t / duration × sentenceCount).

7.5 Menu

  • Toggle it from the header; Escape or the close button closes it.
  • The tablet scrim closes it on click.
  • When closed, the drawer is visibility: hidden, which removes it from tab order.
  • The slide animation runs 280ms with cubic-bezier(.2,.7,.2,1).

7.6 Exit

  • Save & exit opens a modal ("Save and exit?") with the options Keep learning or Save & exit.
  • Confirming saves state and shows a "Your place is saved" screen with Resume course. Escape cancels the dialog.

7.7 Persistence

  • localStorage key waffles101-player stores { idx, visited[], completed[] }.
  • It's written on navigation, on completion, and on exit, and restored on load.
  • Embedded preview instances pass persist={false}.

8. Page templates

All templates live inside the content region and must work at desktop, tablet, and phone widths.

8.1 Title page (page 1)

  • Full-bleed background image fills the entire stage (no card, no padding) using a user-fillable image slot.
  • Scrim for legibility: left-to-right on desktop/tablet (rgba(28,18,12,.86) → .12), bottom-to-top on phone.
  • The text block (max 640px) sits on the left and is vertically centered; on phone it's bottom-anchored:
    • Eyebrow: "Hello and welcome to..." (#FFE3CF)
    • Hero: course title, white
    • Lede: 1–2 sentences, #FFF6EF
    • Meta: "12 pages · 4 modules · no experience needed", hidden in short mode
    • Start the course → is a primary button that goes to page 2 and autoplays it.
  • Overlays use pointer-events: none (the button re-enables it) so the image slot stays droppable.

8.2 Standard content slide (default)

  • Desktop/tablet: two columns at 50/50, image placeholder left and text right.
  • Phone: stacked, with the image at a 180px min height above the text.
  • The text column holds an eyebrow (Page N · Title), an h2 heading, a one-sentence body, and 2–4 bullets marked with 8px brand dots.
  • Image placeholder: a subtle diagonal stripe (#F7F5F2 / #EFECE8, 12px) plus a centered white mono label describing the intended image (e.g. "photo: spatula folding wet into dry batter").

8.3 Accordion (page 4, "Core Ingredients")

  • Desktop/tablet: intro column (38%: eyebrow, heading, lede, image placeholder) and list column (62%, align-self: safe center).
  • Phone: stacked, with the image hidden.
  • Items: 12px radius cards. Closed = #FAF9F7 bg with a #ECE8E3 border. Open = white bg, brand-border border, and the raised shadow.
  • Header: a full-width button (min 56px) inside an h3, showing a 32px number badge (brand-strong bg, white), the name at 16px/600, and a chevron that rotates 180° when open.
  • Panel: description (15px) plus "Typical amount:", indented to align under the name.
  • Only one item is open at a time, the first is open by default, and clicking the open item closes it.
  • ARIA: aria-expanded and aria-controls on the button; the panel is role="region" with aria-labelledby. Closed panels are visibility: hidden.

8.4 Adding a new template

  1. Add a boolean in logic (e.g. isQuiz: s.idx === 11) and exclude that index from isContent.
  2. Render it inside the content region's frame (same radius, border, shadow, overflow: auto).
  3. Use safe center or margin: auto, never plain center, for anything that can overflow a scroll container.
  4. Provide the desktop, tablet, and phone variants plus short-height behavior.
  5. If it has interactions, define what counts as "complete" (§7.2).

9. Accessibility checklist

  • Text contrast ≥ 4.5:1 (≥ 3:1 for headline-scale type only); orange behind text is always #A84600.
  • Global focus ring: :focus-visible { outline: 3px solid #A84600; outline-offset: 2px; } on every control.
  • Targets ≥ 44×44px (phone primary buttons 52px, play 60px).
  • Icon-only buttons have an aria-label plus title tooltip.
  • Toggles use aria-pressed (Captions, Mute); disclosures use aria-expanded (Menu, accordion).
  • Progress bars expose role="progressbar" with aria-valuenow/min/max and a label.
  • Live updates (page counter, captions, toast) use aria-live="polite".
  • Escape closes the menu and the dialog; hidden panels are removed from tab order.
  • Nothing important is conveyed by color alone (status icons differ in shape: check, half-fill, ring, dot).

10. Copy guidelines

  • Voice: friendly, direct, encouraging. Second person ("you'll learn…").
  • Sentence case for headings and buttons ("Start the course", "Save & exit").
  • No em dashes (—) in learner-facing text; use periods or commas.
  • Keep slide body to one or two sentences and bullets to one line each where possible.
  • Use UI labels exactly as written: "Menu", "Course contents", "Course Completion", "Save & exit", "Back", "Next", "Captions", "Transcript", "Section Completed", "You are here", "In progress", "Complete", "Resume course".
  • Numbers read "N of 12" for page counters and "N of 12 pages complete" in the menu.

11. Implementation notes

  • Styling is inline. The only global CSS is font import, box-sizing reset, the focus ring, range accent-color, and link colors (#A84600, hover #8F3B00).
  • Course data lives in COURSE (modules → [title, duration]), NARR (sentences per page), SLIDES (image label, heading, body, points), and INGREDIENTS (accordion items).
  • Props:
    • viewport (auto | desktop | tablet | phone)
    • menuOpen
    • captionsOn
    • showToast (preview the toast)
    • initialPage (1–12)
    • initialTime
    • height
    • persist
